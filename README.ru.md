# 🏘️ parser-toolkit

> Небольшой сборник парсеров недвижимости для РФ — собирает объявления посуточной аренды **с открытыми номерами телефонов хозяев** из ЦИАН, 2ГИС и Яндекс.Карт.

[English version →](README.md)

Каждый парсер работает с источником, где контактные телефоны **лежат открыто** (без капчи, без кнопки «показать телефон»), и отдаёт чистые **CSV + JSON**, готовые для CRM или отдела продаж.

---

## 📦 Что внутри

| Парсер | Источник | Метод | Телефоны | Прокси | API-ключ |
|---|---|---|---|---|---|
| [`cian/`](cian/) | [ЦИАН](https://cian.ru), посуточно | Прямой HTTP (встроенный JSON) | ✅ открытые | 🇷🇺 нужен RU-прокси | — |
| [`2gis/`](2gis/) | [2ГИС](https://2gis.ru), справочник | Apify-актор | ✅ открытые | — (прокси Apify) | токен Apify |
| [`yandex-maps/`](yandex-maps/) | [Яндекс.Карты](https://yandex.ru/maps) | Apify-актор | ✅ открытые | — (прокси Apify) | токен Apify |

Все три дают **разные, дополняющие друг друга базы** — запусти все и дедуплицируй по номеру для максимального охвата.

## 🚀 Быстрый старт

```bash
git clone https://github.com/Rauan228/parser-toolkit.git
cd parser-toolkit
pip install -r requirements.txt   # только stdlib, но пусть будет
```

### 1. ЦИАН — прямой парсер (нужен RU-прокси)

ЦИАН блокирует не-российские IP и отправляет ботов на страницу-заглушку,
поэтому нужен **российский резидентный/мобильный прокси**.

```bash
PROXY="http://user:pass@host:port" python cian/cian_parser.py
```

Доп. env: `CITIES="www,spb,sochi"` (www = Москва), `PAGES=5`, `OUT=my_leads`.

### 2. 2ГИС — через Apify (нужен токен, прокси не нужен)

```bash
APIFY_TOKEN="apify_api_..." python 2gis/twogis_parser.py
```

Доп. env: `CITIES="moscow,spb,sochi"`, `MAX=500`, `OUT=my_leads`.

### 3. Яндекс.Карты — через Apify (нужен токен, прокси не нужен)

```bash
APIFY_TOKEN="apify_api_..." python yandex-maps/yandex_maps_parser.py
```

Доп. env: `QUERIES="квартиры посуточно"`, `CITIES="Москва,Сочи"`, `MAX=200`.

## 📋 Поля на выходе

**ЦИАН** (самые полные): `phone, phone2, city, price_per_day_rub, rooms, area_m2, floor, floors_total, address, metro, build_year, furniture, deposit, owner_id, posted, description, url`

**2ГИС**: `phone, name, city, address, category, url`

**Яндекс.Карты**: `phone, phone2, name, city, address, rating, latitude, longitude, url`

CSV пишется с UTF-8 BOM — кириллица корректно открывается в Excel.

## 🔑 Что понадобится

- **Токен Apify** (2ГИС, Яндекс.Карты): бесплатный на [console.apify.com](https://console.apify.com/account/integrations). Free-план ограничивает число результатов за прогон; небольшое пополнение снимает лимит для полноценного сбора.
- **Российский прокси** (ЦИАН): любой резидентный/мобильный RU-прокси. Рекомендуются sticky-сессии (один IP на сессию).

## ⚙️ Как это работает

- **ЦИАН** парсит серверный JSON-стейт, встроенный в страницу выдачи (`"offers":[…]`), и вырезает сбалансированный массив напрямую — телефоны уже лежат в этом стейте, кликать «показать» не нужно. Цикл ретраев защищает от обрыва (большого) ответа прокси.
- **2ГИС / Яндекс.Карты** дёргают публичные Apify-акторы, которые обходят карточки справочников; оба справочника публикуют телефоны организаций по своей природе.

---

## ⚠️ Важно

- Данные берутся из **публичных объявлений/справочников**. Используй ответственно и в рамках правил каждого источника и законодательства о персональных данных.
- Источники меняют вёрстку/рубрики со временем — селекторы и ID рубрик иногда требуют обновления.
- Сборник — для легального лидогена и исследований. Ответственность за использование данных на тебе.
