# 🧰 parser-toolkit

> Готовые парсеры для трёх больших платформ РФ — **2ГИС**, **Яндекс.Карты** и **ЦИАН**. Собирают объявления и данные организаций **с открытыми телефонами** в чистые CSV + JSON. Что именно собирать — решаешь ты.

[English version →](README.md)

Каждый парсер работает с источником, где контактные телефоны **лежат открыто** (без капчи, без кнопки «показать телефон»). Ищи **любую** категорию — рестораны, автосервисы, клиники, фитнес, недвижимость, что угодно — парсеры не привязаны к нише.

---

## 📦 Что внутри

| Парсер | Источник | Что собирает | Метод | Прокси | API-ключ |
|---|---|---|---|---|---|
| [`2gis/`](2gis/) | [2ГИС](https://2gis.ru) | любые категории бизнеса | Apify-актор | — (прокси Apify) | токен Apify |
| [`yandex-maps/`](yandex-maps/) | [Яндекс.Карты](https://yandex.ru/maps) | любые категории бизнеса | Apify-актор | — (прокси Apify) | токен Apify |
| [`cian/`](cian/) | [ЦИАН](https://cian.ru) | любой раздел недвижимости | Прямой HTTP (встроенный JSON) | 🇷🇺 нужен RU-прокси | — |

- **2ГИС / Яндекс.Карты** — справочники организаций: задай любой поисковый запрос и список городов.
- **ЦИАН** — платформа недвижимости: наведи на любой раздел (аренда, продажа, посуточно, коммерция…) одной env-переменной.

Все три дают **разные, дополняющие друг друга базы** — запусти все и дедуплицируй по номеру для максимального охвата.

## 🚀 Быстрый старт

```bash
git clone https://github.com/Rauan228/parser-toolkit.git
cd parser-toolkit
pip install -r requirements.txt   # только stdlib, но пусть будет
```

### 2ГИС — через Apify (токен, без прокси)

```bash
APIFY_TOKEN="apify_api_..." QUERY="кофейни" CITIES="moscow,spb" python 2gis/twogis_parser.py
```
`QUERY` — что угодно: `рестораны`, `автосервис`, `стоматология`, `квартиры посуточно`, …

### Яндекс.Карты — через Apify (токен, без прокси)

```bash
APIFY_TOKEN="apify_api_..." QUERY="барбершоп" CITIES="Москва,Сочи" python yandex-maps/yandex_maps_parser.py
```

### ЦИАН — прямой парсер (нужен RU-прокси)

ЦИАН блокирует не-российские IP и отправляет ботов на страницу-заглушку,
поэтому нужен **российский резидентный/мобильный прокси**.

```bash
PROXY="http://user:pass@host:port" CIAN_PATH="snyat-kvartiru-posutochno" python cian/cian_parser.py
```
`CIAN_PATH` — любой раздел: `snyat-kvartiru` (долгосрок), `kupit-kvartiru` (продажа),
`kupit-dom`, `snyat-pomeshchenie` (коммерция), … По умолчанию — посуточная аренда.

## 📋 Поля на выходе

**2ГИС**: `phone, name, city, address, category, url`

**Яндекс.Карты**: `phone, phone2, name, city, address, rating, latitude, longitude, url`

**ЦИАН**: `phone, phone2, city, price_rub, rooms, area_m2, floor, floors_total, address, metro, build_year, furniture, deposit, owner_id, posted, description, url`

CSV пишется с UTF-8 BOM — кириллица корректно открывается в Excel.

## 🔑 Что понадобится

- **Токен Apify** (2ГИС, Яндекс.Карты): бесплатный на [console.apify.com](https://console.apify.com/account/integrations). Free-план ограничивает число результатов за прогон; небольшое пополнение снимает лимит.
- **Российский прокси** (ЦИАН): любой резидентный/мобильный RU-прокси. Рекомендуются sticky-сессии (один IP на сессию).

---

## ⚙️ Как это работает

- **2ГИС / Яндекс.Карты** дёргают публичные Apify-акторы, которые обходят карточки справочников по твоему запросу; оба справочника публикуют телефоны организаций по своей природе. Настройка — `QUERY` + `CITIES`, либо (2ГИС) точные URL рубрик через `START_URLS`.
- **ЦИАН** парсит серверный JSON-стейт, встроенный в страницу выдачи (`"offers":[…]`), и вырезает сбалансированный массив напрямую — телефоны уже лежат в этом стейте, кликать «показать» не нужно. Цикл ретраев защищает от обрыва (большого) ответа прокси. Любой раздел ЦИАН — через `CIAN_PATH`.

## ⚙️ Основные env-переменные

| Переменная | Парсеры | Значение |
|---|---|---|
| `APIFY_TOKEN` | 2gis, yandex-maps | токен Apify |
| `PROXY` | cian | `http://user:pass@host:port` (RU-прокси) |
| `QUERY` | 2gis, yandex-maps | поисковый текст (любая категория) |
| `CITIES` | все | города через запятую |
| `CIAN_PATH` | cian | раздел поиска ЦИАН |
| `MAX` / `PAGES` | — | объём на город |
| `OUT` | все | имя выходного файла |

## ⚠️ Важно

- Данные берутся из **публичных объявлений/справочников**. Используй ответственно и в рамках правил каждого источника и законодательства о персональных данных.
- Источники меняют вёрстку/рубрики со временем — селекторы и пути иногда требуют обновления.
- Сборник — для легального сбора данных и исследований. Ответственность за использование на тебе.
