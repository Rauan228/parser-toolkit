# Парсер контактов организаций — инструкция по запуску

Программа собирает опубликованные контакты компаний из **2ГИС** и **Яндекс Карт**: телефоны, почты, WhatsApp, Telegram, Viber и сайты. По желанию дополнительно открывает сайты компаний и ищет контакты на главной странице и страницах «Контакты» / «О компании».

Результат — **Excel с двумя листами «Контакты» и «Компании»**, а также CSV и JSON. На листе «Контакты» каждый телефон, адрес почты или мессенджер занимает отдельную строку. Рядом сохраняются компания, подпись к контакту и ссылка на страницу, где он найден.

Если в источнике написано «отдел продаж», «руководитель» или имя сотрудника, программа сохраняет эту подпись. Если подписи нет, поле остаётся пустым. Наличие телефона не обязательно: компании только с почтой, мессенджером или сайтом тоже попадают в результат.

**Для этого сценария не нужны ChatGPT, Claude, Codex, подписка на ИИ и куки из браузера.** Нужны компьютер, интернет и Python. Программа работает локально, компьютер должен оставаться включённым до окончания сбора.

## 1. Скачать программу

1. **[Скачайте ZIP с готовой версией](https://github.com/Rauan228/parser-toolkit/archive/refs/heads/contacts-ready.zip).**
2. Распакуйте ZIP целиком в удобную папку, например `Документы/parser-toolkit`. Не запускайте программу внутри архива.
3. Откройте распакованную папку. В ней должны лежать `start_windows.bat`, `start_macos.command`, `pyproject.toml` и папка `parser_toolkit`.

Другой способ: откройте [страницу готовой версии](https://github.com/Rauan228/parser-toolkit/tree/contacts-ready), нажмите зелёную кнопку **Code → Download ZIP**. Обновление находится в ветке `contacts-ready`; не переключайтесь на `main` при скачивании этой версии.

## 2. Установить Python — один раз

### Windows 10 / 11

1. Скачайте **Python 3.11 или новее** с [python.org/downloads](https://www.python.org/downloads/). Подойдёт обычный установщик Python 3 для Windows.
2. В установщике включите **Add Python to PATH**. Оставьте включёнными `pip`, Tcl/Tk и IDLE, если установщик предлагает их выбрать.
3. Завершите установку. Если терминал был открыт до установки, закройте и откройте его заново.
4. В папке программы дважды нажмите **`start_windows.bat`**. Если расширения скрыты, файл может отображаться как `start_windows` с типом «Пакетный файл Windows».
5. При первом запуске откроется консоль: программа создаст своё окружение `.venv` и скачает библиотеку для Excel. Дождитесь окна **«Сбор контактов компаний»**. При следующих запусках тот же файл проверяет установку и открывает окно.

Если двойной щелчок не сработал, используйте [запуск вручную](#запуск-вручную-через-терминал).

### macOS

1. Скачайте и установите **Python 3.11 или новее** с [python.org/downloads/macos](https://www.python.org/downloads/macos/). Для окна программы нужна сборка с Tkinter; официальный установщик Python обычно включает её.
2. В распакованной папке дважды нажмите **`start_macos.command`**.
3. Дождитесь установки и появления окна программы.

Если macOS не позволяет выполнить файл или сообщает об отсутствии прав, откройте приложение **Терминал**, перейдите в папку программы и выполните:

```bash
cd ~/Downloads/parser-toolkit-contacts-ready
bash start_macos.command
```

Замените путь после `cd` на свою папку. Её можно перетащить из Finder в Терминал после набранного `cd `.

### Linux

Нужны Python 3, модуль `venv` и Tkinter. Например, для Ubuntu / Debian:

```bash
sudo apt install python3-venv python3-tk
```

В папке программы:

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[contacts]"
.venv/bin/python -m parser_toolkit gui
```

Для Fedora Tkinter устанавливается командой `sudo dnf install python3-tkinter`. Если окно недоступно, все функции сбора работают [из терминала](#запуск-вручную-через-терминал).

## 3. Собрать первую небольшую таблицу

В открывшемся окне:

1. **Источник:** оставьте `2ГИС`. Можно выбрать `Яндекс Карты` или `Оба источника`.
2. **Город:** укажите нужный город, например `Москва`, `Алматы` или `Астана`. В поле уже стоит пример — замените его на свой город.
3. **Категория или название компании:** напишите, что искать, например `типография`, `стоматология`, `строительная компания` или конкретное название организации.
4. **Лимит:** для первого запуска поставьте `10`. Это максимум организаций на каждый город и источник, а не число телефонов. Реальное количество может быть меньше.
5. **Папка результатов:** выберите, куда сохранить таблицу, или оставьте `output` внутри папки программы.
6. Оставьте галочку **«Дополнительно искать контакты на сайтах компаний»**, если нужны дополнительные почты и подписи к контактам. Без галочки собираются только данные карт, сбор обычно быстрее.
7. Нажмите **«Собрать контакты»** и дождитесь сообщения о завершении. Внизу виден журнал работы. Не закрывайте программу во время сбора.
8. Нажмите **«Открыть результаты»** и откройте файл с расширением **`.xlsx`**.

Для следующего поиска поменяйте город или запрос и снова нажмите кнопку. Каждый запуск из окна создаёт файлы с новым временем в названии и не затирает предыдущий результат.

Для нескольких городов перечислите их через точку с запятой: `Москва; Казань; Самара`. Несколько категорий запускайте по очереди: один запрос — один сбор.

Пример: `2ГИС`, город `Москва`, запрос `производство мебели`, лимит `50`, поиск на сайтах включён. Программа получает компании из выдачи 2ГИС, затем читает основной сайт каждой компании: главную и найденные внутренние страницы контактов, всего до трёх страниц на компанию. Полный интернет она не обходит.

## 4. Что находится в результате

Например, после запуска появятся:

```text
contacts_2026-11-03_15-30-00_123456.xlsx
contacts_2026-11-03_15-30-00_123456.contacts.csv
contacts_2026-11-03_15-30-00_123456.companies.csv
contacts_2026-11-03_15-30-00_123456.json
contacts_2026-11-03_15-30-00_123456.run.json
contacts_2026-11-03_15-30-00_123456.log.txt
```

| Файл / лист | Для чего нужен |
| --- | --- |
| Excel → **Контакты** | Одна строка — один контакт. Здесь удобно фильтровать телефоны, почты, мессенджеры и подписи. |
| Excel → **Компании** | Одна строка — одна карточка компании, все её контакты сгруппированы. |
| `contacts.csv` | Та же подробная таблица контактов для Excel / импорта в другую программу. |
| `companies.csv` | Сводная таблица компаний. |
| `.json` | Полные структурированные результаты; пригодятся для дальнейшей обработки. |
| `.run.json` | Итоги запуска: количество компаний, ошибки источников и недоступные страницы сайтов. |
| `.log.txt` | Текстовый журнал из окна; можно прислать Рауану для разбора ошибки. |

На листе **«Контакты»** есть:

| Столбец | Значение |
| --- | --- |
| Компания, город, адрес, категория | К какой организации относится контакт. |
| Тип контакта | Телефон, почта, WhatsApp, Telegram, Viber, сайт или другая опубликованная соцсеть. |
| Контакт | Сам номер, адрес почты или ссылка. |
| Подпись в источнике | Подпись из карточки либо короткий фрагмент текста рядом с контактом на сайте. Может содержать имя, отдел или роль. Это текст источника, а не подтверждённая должность. |
| Добавочный | Добавочный номер, если он указан и распознан отдельно. |
| Где найден | Адрес страницы, с которой взят конкретный контакт. |
| Карточка компании | Ссылка на карточку в 2ГИС или Яндекс Картах. |
| Источник, ID компании | Помогают сопоставлять и проверять записи. |

Один номер может встречаться несколько раз: у разных филиалов, с разными подписями или на разных страницах. Филиалы с общим телефоном сохраняются отдельно. В режиме «Оба источника» одна компания может присутствовать и из 2ГИС, и из Яндекса; автоматически объединять такие карточки программа не пытается.

В Excel номера хранятся текстом, чтобы сохранялся `+7`. Лучше пользоваться `.xlsx`. Если открываете CSV: кодировка **UTF-8**, разделитель **точка с запятой**, тип столбца «Контакт» — **Текст**. Для защиты от выполнения формул CSV может содержать апостроф перед номером или значением, начинающимся с `+`, `=`, `-`, `@`.

## 5. Что важно понимать о полноте данных

- Программа собирает **опубликованные контакты**, доступные в ответах карт и HTML сайтов. Это не гарантия полной базы всех организаций города.
- Наличие компании в таблице не означает, что у неё обязательно есть почта или контакт руководителя. Контакт может отсутствовать в источнике.
- На сайтах читаются обычные ссылки `tel:`, `mailto:`, мессенджеры, видимые адреса почты и российские / казахстанские номера формата `+7` / `8`. Иностранные номера из ссылок `tel:` также сохраняются. Текст на картинках, в PDF, за авторизацией или подгружаемый только JavaScript отдельно не распознаётся.
- Для сайта используется первый основной сайт из карточки. Не все страницы и не все дополнительные сайты обходятся. Ссылки на страницы контактов ищутся на самом сайте; если их нет, программа не угадывает адреса страниц.
- Подпись сохраняется, когда её удалось связать с конкретным контактом. Она может быть пустой или содержать короткий контекст. Для важных записей проверьте страницу из столбца «Где найден».
- Проверка существования почты, доступности телефона и принадлежности человеку не выполняется. Сообщения и звонки программа не отправляет.
- Куки для 2ГИС / Яндекс Карт в этом сценарии **не требуются и не запрашиваются**. Инструкции о куки в других разделах репозитория относятся к другим парсерам, например объявлениям недвижимости и авто.
- Отдельные государственные и коммерческие реестры в этот сценарий пока **не подключены**. Для добавления конкретного реестра нужен его адрес и пример нужных данных.
- Карты могут ограничивать запросы, показывать капчу или менять формат. Программа не решает капчу автоматически. Пустой результат не доказывает отсутствие компаний.

Промежуточные CSV и JSON сохраняются после обработки города / источника и затем после каждого обработанного сайта. Excel создаётся по завершении сбора. Если закрыть окно посреди работы, уже сохранённые файлы останутся, текущая операция может не сохраниться. Автоматического продолжения того же запуска в окне нет — новый запуск начнёт новый сбор.

## 6. Если возникла проблема

### Окно сразу закрывается / Python не найден

На Windows переустановите Python с галочкой **Add Python to PATH**. Откройте папку программы, в адресной строке Проводника наберите `cmd`, нажмите Enter и выполните `start_windows.bat` — сообщение останется видимым.

На macOS запустите `bash start_macos.command` из Терминала. Если появляется `CERTIFICATE_VERIFY_FAILED`, в папке `/Applications/Python 3.x/` запустите `Install Certificates.command`, если он есть в вашей установке.

### Ошибка `No module named tkinter` / не найдена библиотека Tk

Windows / macOS: установите Python с Tcl/Tk с python.org. Linux: установите системный пакет Tkinter из раздела установки. Для работы без окна используйте команды ниже.

### `No module named parser_toolkit` / отсутствует `pyproject.toml`

Команда выполнена не из папки проекта или установка не завершилась. В текущей папке должны быть `pyproject.toml` и папка `parser_toolkit`. Сначала перейдите туда, затем повторите установку.

### Не удаётся установить зависимости

При первом запуске нужен доступ к интернету и Python Package Index. В журнале не должно быть ошибок `pip`. Проверьте интернет, затем повторно запустите стартовый файл. Не удаляйте папку `parser_toolkit`; окружение `.venv` при необходимости можно удалить и создать заново стартовым файлом.

### Найдено 0 компаний

1. Проверьте город и запрос. Начните с известной категории и лимита `10`.
2. Откройте тот же поиск вручную в браузере.
3. Посмотрите журнал: `403`, `429`, `captcha`, `limited`, `blocked` означают ограничение доступа; ошибка формата может означать изменение сайта.
4. Попробуйте другой источник. При ограничении запросов подождите и повторите позже. Увеличение лимита не снимает блокировку.
5. Если 2ГИС сообщает о заблокированном ключе, перезапуск или ручное копирование куки не гарантируют исправления. Пришлите Рауану журнал; может потребоваться обновление интеграции или доступный Catalog API key.

### Есть телефоны, но нет почты / WhatsApp / роли

Эти данные могут отсутствовать в карточке. Включите поиск на сайтах и выполните новый запуск. Если на сайте данные видны только на картинке, в PDF или после нажатия кнопки, этот сбор может их не увидеть.

### Часть сайтов недоступна

Собранные контакты карт сохраняются. В `.run.json` список проблем находится в `website_errors`. Например, сайт может не отвечать, требовать JavaScript, запрещать запросы или иметь ошибку сертификата. Поиск по другим компаниям продолжается.

### Не создаётся Excel / `Permission denied`

Закройте Excel-файл, если он открыт. Проверьте доступ к папке результата и свободное место. Если не установлена библиотека Excel, CSV и JSON всё равно доступны; для Excel повторите установку с `.[contacts]`, как ниже.

### Сбор идёт долго

Поиск на сайтах добавляет запросы для каждой компании. Начните с 10–20 организаций и одного города. Паузы между запросами предусмотрены; время зависит от числа компаний и доступности сайтов. Если нужны только контакты карт, выключите галочку сайтов.

Если ошибка остаётся, пришлите Рауану `.log.txt` и `.run.json`, название источника, город и запрос. Не присылайте пароли и куки. Учтите, что журнал и отчёт могут содержать названия компаний и адреса сайтов.

## Запуск вручную через терминал

Графическое окно — рекомендуемый способ для обычной работы. Команды пригодятся для диагностики и запуска без окна.

### Windows — первая установка

Откройте `cmd` в папке проекта:

```bat
py -3 -m venv .venv
.venv\Scripts\python.exe -m pip install -e ".[contacts]"
.venv\Scripts\python.exe -m parser_toolkit gui
```

Если `py` не найден, замените первую команду на `python -m venv .venv`.

### macOS / Linux — первая установка

```bash
python3 -m venv .venv
.venv/bin/python -m pip install -e ".[contacts]"
.venv/bin/python -m parser_toolkit gui
```

### Команды сбора

В Windows используйте `.venv\Scripts\python.exe`, в macOS / Linux — `.venv/bin/python`. Ниже показан вариант для macOS / Linux:

```bash
# 2ГИС: первые 10 организаций, дополнительно читать сайты
.venv/bin/python -m parser_toolkit contacts --source 2gis --query "типография" --city "Москва" --max 10 --websites --out output/print_moscow

# Яндекс Карты: только контакты из карт
.venv/bin/python -m parser_toolkit contacts --source yandex-maps --query "стоматология" --city "Алматы" --max 20 --out output/dentists_almaty

# Оба источника и несколько городов
.venv/bin/python -m parser_toolkit contacts --source both --query "производство мебели" --city "Москва" --city "Казань" --max 30 --websites --out output/furniture

# Показать параметры
.venv/bin/python -m parser_toolkit contacts --help
```

В отличие от окна, **повторный запуск команды с тем же `--out` перезаписывает предыдущие файлы**. Указывайте новый путь для нового сбора. Не указывайте `.xlsx` в `--out`, расширения добавляются автоматически.

| Параметр | Что задаёт |
| --- | --- |
| `--source 2gis` / `yandex-maps` / `both` | Источник. По умолчанию 2ГИС. |
| `--query "…"` | Категория или название компании. Обязательный. |
| `--city "…"` | Город. Обязательный, повторяется для нескольких городов. |
| `--max 50` | Максимум организаций на город и источник. По умолчанию 50. |
| `--websites` | Дополнительно искать на сайтах. В командах по умолчанию выключен, в окне включён. |
| `--website-pages 3` | Максимум страниц основного сайта на компанию, включая главную. |
| `--out output/name` | Префикс файлов результата. По умолчанию `output/contacts`. |
| `--timeout 20` | Таймаут одного запроса, секунды. |
| `--sleep 1` | Пауза между страницами и сайтами, секунды. |
| `--proxy "http://…"` | Необязательный HTTP-прокси; обычный запуск не требует его. |
| `--no-excel` | Только CSV и JSON. |

Код завершения команды: `0` — собраны организации, `1` — ошибка источника или пустой результат, `2` — ошибка параметров, `130` — остановка через Ctrl+C. Если часть дополнительных сайтов недоступна, команда сохраняет данные карт и завершается с `0`, а отчёт получает статус `partial` и список `website_errors`. Проверяйте отчёт, если нужна оценка полноты. При Ctrl+C сохраняются уже обработанные организации; чтение текущего источника может не успеть завершиться.

Командный запуск создаёт отчёт `.run.json`, но не отдельный `.log.txt`. Чтобы сохранить журнал, можно перенаправить вывод команды в файл: добавьте `> run.log.txt 2>&1` в её конец.

## Обновление программы

Скачайте свежий ZIP, распакуйте в новую папку и запустите стартовый файл. Старую папку с результатами оставьте: её содержимое само не переносится. Не копируйте `.venv` между компьютерами или разными установками Python.

## Для разработчиков

Остальные парсеры репозитория (недвижимость, авто), их ограничения и прежние команды описаны в [README.md](README.md). Этот контактный сценарий использует 2ГИС, Яндекс Карты и публичные сайты компаний; куки-парсеры объявлений запускаются отдельно.

```bash
python -m unittest discover -s tests -v
```

Тесты используют локальные примеры и подменённые HTTP-ответы. Они не доказывают доступность внешних сайтов. Используйте опубликованные данные с учётом условий источников.
